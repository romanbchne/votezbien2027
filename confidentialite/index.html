Confidentialité et données du quiz

Le code du quiz enregistre votre progression dans le stockage local de votre navigateur. Le dépôt audité ne contient pas de fonction qui transmet vos réponses à un serveur.

Réponses et progression

Vos réponses peuvent révéler vos opinions politiques. Le site les conserve dans le localStorage de l’appareil afin de calculer et de reprendre votre parcours. Aucun compte n’est demandé et le dépôt ne contient pas d’outil de mesure d’audience ou de publicité.

Les fichiers de polices chargés depuis Google Fonts nécessitent une requête vers ce fournisseur lorsque la page les utilise. Cette requête ne contient pas les réponses au quiz. GitHub Pages sert les fichiers du site; les informations et durées de conservation relatives aux journaux techniques de l’hébergeur restent à vérifier par l’éditeur.

Vous pouvez supprimer les données du site dans les réglages de stockage de votre navigateur. La durée de conservation exacte et une procédure de suppression directement depuis le site sont à compléter par l’éditeur.

Responsable et exercice des droits

Responsable du traitement : À compléter. Pour exercer les droits applicables ou poser une question sur les données, contactez l’éditeur : À compléter. L’identité du responsable, la base juridique, les durées de conservation et les modalités de contact doivent être finalisées par l’éditeur.

La CNIL explique les informations à fournir aux personnes dans son guide sur les principes de protection des données. Consultez également les mentions légales et la page Contact.

Le lien vers la cagnotte ouvre un service externe seulement si vous choisissez de le suivre : voir la cagnotte OnParticipe.
