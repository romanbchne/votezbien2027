Confidentialité et données du quiz

Le quiz conserve vos réponses dans le stockage local de votre navigateur afin de calculer votre résultat et de vous permettre de reprendre votre parcours. Le code du site ne les envoie pas au serveur.

Réponses et progression

Vos réponses peuvent révéler vos opinions politiques. Elles sont enregistrées sur votre appareil dans le stockage local du navigateur, sans création de compte. L’application les utilise pour calculer le résultat et garder votre progression; l’éditeur ne peut pas les consulter depuis le site. Elles restent dans le navigateur jusqu’à ce que vous effaciez les données de ce site dans ses réglages. Le quiz ne propose pas de bouton distinct de suppression.

Le site n’intègre pas de publicité ni de mesure d’audience dans son code. Il charge toutefois les polices Google Fonts et certains portraits depuis Wikimedia Commons. Ces requêtes transmettent aux services concernés les informations techniques habituelles d’une requête web, comme votre adresse IP, mais pas vos réponses au quiz.

Hébergement et services externes

GitHub Pages indique que l’adresse IP des visiteurs est enregistrée dans ses journaux à des fins de sécurité. Pour en savoir plus, consultez la documentation GitHub Pages et la déclaration de confidentialité de GitHub.

Le lien vers la cagnotte ouvre OnParticipe uniquement si vous choisissez de le suivre. Les données que vous fournissez ensuite sont traitées par ce service selon ses propres règles : consulter la cagnotte OnParticipe.

Les services externes ont leurs propres politiques de confidentialité et peuvent traiter les données techniques de connexion selon leurs conditions.

Maîtriser vos données

Pour effacer les réponses du quiz, supprimez les données de stockage de votre navigateur pour votezbien2027.fr. Pour les journaux d’hébergement ou les traitements réalisés par un service externe, consultez la politique de confidentialité du fournisseur concerné et ses moyens de contact.

Pour en savoir plus sur vos droits et la protection des données, consultez les repères de la CNIL et les mentions légales de Votez bien.
