Confidentialité et données du quiz

Le code du quiz enregistre votre progression dans le stockage local de votre navigateur. Le dépôt audité ne contient pas de fonction qui transmet vos réponses à un serveur.

Réponses et progression

Vos réponses peuvent révéler vos opinions politiques. Le site les conserve dans le stockage local de votre navigateur pour calculer et reprendre votre parcours; elles restent sur votre appareil jusqu’à leur suppression dans les réglages du navigateur. Aucun compte, outil de mesure d’audience ou publicité n’est utilisé par le code du site.

Le chargement des polices Google Fonts et des portraits hébergés sur Wikimedia Commons entraîne des requêtes à ces services, sans transmettre les réponses au quiz. GitHub Pages indique que les adresses IP des visiteurs sont inscrites dans ses journaux à des fins de sécurité. Consultez la documentation GitHub Pages sur les données collectées et la déclaration de confidentialité de GitHub.

Vous pouvez effacer votre progression en supprimant les données de ce site dans les réglages de stockage de votre navigateur; l’application ne propose pas de bouton distinct de suppression.

Responsable et exercice des droits

Le nom du responsable du traitement et son adresse de contact ne figurent pas dans le dépôt. Ils doivent être ajoutés par l’éditeur, avec la base juridique et les durées applicables, avant que cette notice puisse être considérée comme complète. Les demandes peuvent ensuite être adressées à ces coordonnées.

La CNIL explique les informations à fournir aux personnes dans son guide sur les principes de protection des données. Consultez également les mentions légales.

Le lien vers la cagnotte ouvre un service externe seulement si vous choisissez de le suivre : voir la cagnotte OnParticipe.
